Scorer note for this dump (#295 plan review, issue comment 7120735225). verdict-rule.txt is the bar, unchanged.

- Each question's dump has an ANSWER block (claims C1.., adjacent items A1.., gaps G, caveats, and COMPUTABILITY lines,
  which are a box written by code and shown with the answer) and, after it, an EVIDENCE LIST block.
- Judge PASS / FAIL on what the answer asserts: its sentences, their cited passages, the gaps, the caveats and the
  Computability box. The EVIDENCE LIST is context only, not answer content: the page shows it under the answer
  (one line per evidence item), but an answer does not pass because a needed fact sits only in the evidence list.
  You may use it to check what evidence existed.
- For every PASS add "text_only": true or false: true if the PASS holds on the answer text and its citations alone,
  reading nothing from the evidence list; false if you leaned on the evidence list. For a FAIL, "text_only": null.

Output: one JSON object, keys = the question ids of your part, in order, each
  {"verdict": "PASS"|"FAIL", "class": "" or e.g. "s" / "b, r", "borderline": true|false, "text_only": true|false|null,
   "reason": "<one line>"}
