# 0058 - Date quality check across C2 documents; undated pages by ADR-007 T-09

Issue: #58    Role: C2    Spec: specs/transcripts-ir.md (also touches specs/retrieval.md - S1,
specs/answer-citations.md - S2, specs/ui.md - U1)

## Goal
Every C2 document (transcript, press, deck) has its published_at checked against what the stored file
prints, by a re-runnable offline script that writes a report of where each date came from. The 8 undated
recruiting/affiliation pages (Q2, Q4, Q6, Q14) enter the corpus dated by the stored copy and marked
date_basis = retrieved, so they never enter a recency window (Q26, Q27), and every place that shows a
date says "page content as of <date>" for them (ADR-007 T-09).

## Files to change
- scripts/check_dates.py (new, C2) - offline: reads data/manifest.csv and the raw files (cee.config.resolve_path),
  rows with doc_type transcript/press/deck. Pure detect(row, texts, meta_date) and judge(...) per family:
  deck p1 "Month D, YYYY" (fallback PDF creationDate, 0-1 day before); investor-day decks case-insensitive,
  first 10 pages, "as of" preferred; MS/SCHW press dateline; RJF press date before "FOR IMMEDIATE RELEASE";
  BAC press (no printed date) cross-checked against same entity+period deck/transcript; transcripts header
  line 1, strong when the MarketBeat URL date or an S&P footer agrees, else "weak"; MER newsroom line 2;
  undated pages: "Content as of" + T-09 chain header. Fails (exit 1) on MISMATCH, published_at < 2015,
  > added_at, > today, < period_end, source-dated with no date found, retrieved with a printed date or no
  T-09 line or header date != published_at. Exit 2 on a missing raw file unless --skip-missing. Allowed
  exceptions: a NOTES dict in the script (doc_id, rule) -> note, empty today. Writes a Markdown table
  doc_id | published_at | date_basis | date source | evidence | verdict, plus counts, to stdout and --out.
- docs/C2_DATES.md (new, generated by the script) - the acceptance report.
- tests/test_check_dates.py (new) - inline fixtures, no network/DB: one case per detector, BAC cross-check
  with and without a sibling, every fail rule, a note silences only its rule, main() exit codes 0/1/2.
- scripts/convert_undated_web.py (new, C2) - fetch (MER live; RJ via Wayback id_ copies; honest generic
  user agent, no email; 5 s delay) and convert with cee.ingest.webpage.article_text plus per-site cut
  phrases. Asserts: no archive markers, no email address or phone number (removes the RJ recruiter block),
  a must-have phrase per page, >= 500 chars. Header: title; "<firm> advisor recruiting page - content as of
  <date>"; Source line (live fetch date or Wayback copy timestamp); "Content as of: <date> (date basis:
  retrieved; the page prints no date)"; "Date check (ADR-007 T-09): printed none; metadata none; HTTP
  Last-Modified none; earliest Wayback capture <date> (dates the URL, not this text)". Deterministic
  (same bytes -> same sha256).
- data/manifest.csv - +8 rows, doc_type press, tier 3, date_basis retrieved, period_end empty:
  MER-PR-web-advisor-development-program, MER-PR-web-becoming-a-merrill-lynch-advisor,
  RJF-PR-web-affiliation-options, RJF-PR-web-traditional-employee-advisor, RJF-PR-web-independent-advisor,
  RJF-PR-web-independent-ria-custody-services, RJF-PR-web-bank-and-credit-union-advisors,
  RJF-PR-web-advisor-select. url: MER live URL; RJ Wayback copy URL.
